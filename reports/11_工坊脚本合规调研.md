# 创意工坊能否用 bat 安装脚本分发（2026-11-01 调研）

问题：工坊物品里带 BepInEx/XUnity 的 DLL 和 bat/ps1 安装脚本，订阅后由玩家手动运行一次，Steam 是否允许？

## 结论

**Valve 没有明文禁止。** 现行规则里找不到“工坊物品不得包含脚本/可执行文件/DLL”的条款，上传时也没被拦（v1.0.0～1.0.2 都正常提交）。但这属于“没被禁止、风险自担”，不是“明确允许”：

- Valve 保留**以任何理由**移除工坊内容的权利，执行方式是**有人举报 → 版主审核**。
- 2026 年工坊连出两起恶意代码事件，Valve 对“带代码的工坊物品”明显收紧（见下）。
- 订户协议要求工坊投稿是**上传者原创**，而本物品内置了第三方的 BepInEx/XUnity 二进制文件，字面上有出入（开源许可允许再分发，但那是另一回事）。

最坏情况是物品被下架，账号可能被暂停社区功能一段时间；目前没看到因“带安装脚本”本身被处理的先例。

## 规则原文要点

| 来源 | 相关内容 |
|---|---|
| Steam 订户协议 §6 | 上传者保证对内容“有足够的权利”；工坊投稿“由你原创”；Valve “可以以任何理由限制或移除工坊投稿” |
| Steam 在线行为准则 | 禁止上传或链接恶意软件（病毒、木马）；禁止上传你没有权利的内容 |
| 讨论、评测与用户生成内容规则 | 工坊内容：不传没有权利的内容、内容要与所在版块相符；版主根据举报审核，违规会删除内容，并可能暂停相关功能或全部社区功能 |
| Steamworks 工坊文档 | 只说上传工具应“只接受游戏会加载的文件格式”，对脚本/DLL 没有任何规定 |
| 本游戏工坊“关于”页 | “立即可用项目”模式：不需要开发者审核，开发者没写额外规则 |

## 先例与趋势

- **允许的一面**：不少游戏的工坊本来就分发 DLL 模组（由游戏自己加载）。Black Mesa 有工坊物品要求玩家把 `.bat` 启动器复制到游戏目录再运行，和我们的形式很像。
- **Wallpaper Engine（2026 年 6 月）**：卡巴斯基发现工坊壁纸里夹带后门和盗号程序，主要针对中国用户。Valve 删除了被点名的物品，但仍然是事后处理。
- **People Playground（2026 年 9 月）**：工坊 C# 模组传播恶意代码。据开发者说，Valve 删除了**所有含 C# 代码的物品**，以及某日期之后上传或更新的全部物品；开发者随后宣布不再支持 C# 模组。
  → 说明一旦出事，Valve 会**按“是否带代码”整批清理**，不逐个甄别。
- **杀毒软件误报**：BepInEx 的 `winhttp.dll`（Doorstop 代理 DLL）常被启发式引擎报成“类木马”。玩家一报毒就可能去举报。

## 本物品的风险点

1. 物品里有 224 个第三方 DLL（.NET 运行时 184、BepInEx 33、XUnity 6、`winhttp.dll` 代理加载 1），正是最近被重点盯的“带代码物品”。
2. 中文玩家刚经历过 Wallpaper Engine 事件，看到“订阅后运行 bat”会更警惕，误报加举报的概率不低。
3. 本游戏工坊只用于关卡和 Mod（标签都是 Toy-Box Map / Mod），汉化物品放在这里算“与版块相符”的灰色地带；游戏不会加载它，只是借道分发。
4. 内置第三方二进制与“原创”保证有出入。

## 可选的降低风险做法

| 做法 | 效果 | 代价 |
|---|---|---|
| A. **精简物品**：工坊只放译文、配置模板和安装脚本；安装时从 BepInEx/XUnity 官方地址下载固定版本的 zip，校验 SHA256 后再装 | 物品里没有任何 DLL，“原创”条款也说得通；就算 Valve 按“带代码”清理也不受影响 | 要改安装脚本并重新测试；安装时要联网（BepInEx 首次启动本来就要联网下载 Unity 库，影响不大）；依赖官方地址长期可用 |
| B. **说明透明化**：介绍里列出安装哪些文件、脚本是纯文本可以自己查看、给出 DLL 与官方发布包一致的校验值、说明 `winhttp.dll` 误报 | 减少误解和举报 | 很小 |
| C. **征得开发者 N7T-GAMES 同意**（最好请对方在工坊或 Discord 认可） | 开发者不会把它当违规内容处理，举报时也有依据 | 需要用户本人联系 |
| D. **备用渠道**：同一份包同时放在 GitHub Releases 等处 | 工坊下架后玩家仍能拿到 | 需要用户的 GitHub 账号，公开发布要征得同意 |

建议：**A + B 一起做**，有条件再做 C。D 视情况。
