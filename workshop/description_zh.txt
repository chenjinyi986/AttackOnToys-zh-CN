[h1]Attack on Toys 简体中文汉化[/h1]

为《Attack on Toys》制作的完整简体中文汉化。译文事先翻译好并在游戏内逐项校对；运行时不联网、不调用任何在线机器翻译，也不修改任何游戏原文件。

[h2]Mod 技术[/h2]
[list]
[*]游戏基于 Unity 2019.4（IL2CPP）制作，本身没有语言切换功能，创意工坊也只能加载关卡和模型 Mod，无法直接加载翻译。因此本汉化通过创意工坊分发，订阅后需运行一次安装脚本。
[*]插件加载器：[b]BepInEx 6（IL2CPP 版）[/b]，在游戏启动时由 Doorstop（winhttp.dll）载入。
[*]文本替换：[b]XUnity.AutoTranslator[/b]，在运行时拦截界面文字，按本汉化的译文表替换为中文。数值、玩家名、按键提示、多句对话等动态拼接的文本，由一百多条正则规则处理。
[*]字体：使用 Windows 系统中文字体自动回退，无需额外字体包。
[*]译文直接从本物品目录读取，汉化更新会随创意工坊自动生效。
[/list]

[h2]翻译范围[/h2]
约 3,300 条译文和 110 余条动态文本规则，覆盖：
[list]
[*]主菜单、设置、按键绑定、帮助、存档、排行榜、分屏
[*]全部任务名称、任务简报与目标
[*]新兵训练营全部 NPC 对话
[*]战斗界面、物品栏、商店、小队、属性卡片
[*]全部兵种、武器、载具、塔楼、建筑的名称与说明
[*]玩具箱（关卡编辑器）全部分类和 1500 余个物品名称
[/list]
玩家名、社区作品名、按键名按惯例保留英文。

[h2]制作工具[/h2]
本汉化使用 Anthropic 的 AI 编程助手 [b]Claude Code[/b] 制作：从游戏资源提取原文、运行时文本采集、翻译与术语统一、动态文本规则编写、安装脚本和打包上传，均由 Claude Code 完成，并在游戏内逐项测试校对。

[h2]安装方法（只需一次）[/h2]
[olist]
[*]订阅本物品，等待 Steam 下载完成。
[*]打开本物品的文件夹：[i]<Steam 库>\steamapps\workshop\content\1269690\{ITEM_ID}[/i]
（Steam 库里右键 Attack on Toys → 管理 → 浏览本地文件，然后向上两级回到 steamapps，再依次进入上面的路径。）
[*]双击 [b]安装汉化.bat[/b]，按提示操作。
[*]启动游戏。[b]第一次启动需要 1～3 分钟[/b]准备（会联网下载一次约 5 MB 的 Unity 基础库），之后就正常了。
[/olist]
备用下载：创意工坊下载不了时，也可以从 GitHub 下载压缩包，内容相同：https://github.com/chenjinyi986/AttackOnToys-zh-CN/releases

[h2]更新与卸载[/h2]
[list]
[*]汉化更新随创意工坊自动下载，重启游戏后生效，一般不需要重新安装；如果更新说明要求重装，再运行一次 [b]安装汉化.bat[/b]。
[*]Steam 有时不会马上推送更新：可以在游戏主菜单 → 我的模组（扳手图标）→ 点“更新创意工坊”立即下载，然后重启游戏。
[*]游戏更新后汉化失效时，也再运行一次安装脚本。
[*]想恢复英文：运行 [b]卸载汉化.bat[/b]，然后可以取消订阅。
[/list]

[h2]安全与透明[/h2]
[list]
[*][b]脚本是纯文本[/b]：两个 bat 除了设置控制台编码和暂停窗口，只做一件事：用 PowerShell 运行 installer 文件夹里对应的 .ps1 脚本（-ExecutionPolicy Bypass 只对这一次运行有效，不改系统设置）。所有脚本都可以用记事本打开查看。
[*][b]安装脚本只做三件事[/b]：定位游戏目录（只读取注册表里的 Steam 路径，不写注册表）；把加载器复制到游戏根目录（BepInEx\、dotnet\、winhttp.dll、doorstop_config.ini、.doorstop_version）；写入翻译插件配置和一个安装记录。不修改、不删除任何游戏原文件，安装过程不联网。
[*][b]卸载脚本[/b]只删除上面这些新增的文件，删除前列出清单并让你确认。
[*][b]DLL 来源[/b]：payload 文件夹里的 DLL 全部取自 BepInEx 6.0.0-be.791 和 XUnity.AutoTranslator 5.6.3.1 的官方发布包，没有做任何修改。物品内的 [b]校验值.txt[/b] 列出每个文件的 SHA256 以及官方压缩包的下载地址和校验值，可以自行核对。
[*][b]联网情况[/b]：游戏第一次启动时，BepInEx 会从官方地址 unity.bepinex.dev 下载一次 Unity 基础库（BepInEx 的正常行为）；汉化本身运行时不联网，不调用任何机器翻译。
[*][b]杀毒软件报 winhttp.dll[/b]：这是 BepInEx 的启动器（Doorstop）。它利用 Windows 优先加载游戏目录里同名 DLL 的机制，在游戏启动时载入 BepInEx。这种加载方式和部分恶意软件相似，所以常被启发式引擎误报。可以按校验值.txt 核对，或上传到 virustotal.com 查询，确认后再加入信任。
[/list]
